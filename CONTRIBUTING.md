# Contributing

Compute Central is a personally maintained project. **External contributions are not accepted.**

- Pull requests from outside collaborators will be closed without review or merge.
- Please do not submit content, corrections, or feature requests as pull requests.

If you find a security issue, report it privately as described in [SECURITY.md](SECURITY.md).

Thank you for reading [computecentral.in](https://computecentral.in/).
