# Security Policy

## Supported Versions

Only the live site at [computecentral.in](https://computecentral.in/), built from the `main` branch, is supported.

## Reporting a Vulnerability

**Do not report security issues in public issues, pull requests, or discussions.**

Report privately using GitHub's [private vulnerability reporting](https://github.com/sameeralam3127/compute-central-docs/security/advisories/new). Include:

- The affected page URL or file
- A description of the issue and its impact
- Steps to reproduce, if applicable

Reports are reviewed on a best-effort basis. Please allow reasonable time for a fix before any public disclosure.

## Scope

In scope: the site's build configuration, workflows, custom templates and scripts, and anything that could expose visitors to harm (for example injected scripts or malicious links).

Out of scope: vulnerabilities in third-party tools discussed in the documentation. Report those to the relevant vendor.
